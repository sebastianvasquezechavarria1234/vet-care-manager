# 🐾 VetCare Manager

Welcome to **VetCare Manager**! This is a robust and efficient Veterinary Clinic Management System built with **ASP.NET Core MVC**. 🏥✨

This application is designed to streamline the daily operations of a veterinary clinic by providing full CRUD (Create, Read, Update, Delete) capabilities to manage patients (pets), their owners, and medical appointments. 🐶🐱

## ✨ Features

- **🐾 Pet Management:** Easily register new animals, update their medical records, and track patient history.
- **🧑‍🤝‍🧑 Owner Registry:** Maintain a comprehensive database of pet owners and their contact information.
- **📅 Appointment Scheduling:** Seamlessly book, edit, and cancel medical appointments for the pets.
- **⚙️ MVC Architecture:** Clean, scalable, and maintainable codebase following the Model-View-Controller design pattern.

## 🛠️ Technologies Used

- **Framework:** ASP.NET Core MVC 🌐
- **Language:** C# 💻
- **Frontend:** HTML5, CSS3, Bootstrap (for responsive design) 🎨

## 🚀 Getting Started

To get a local copy up and running, follow these simple steps:

1. **Clone the repository**
   ```bash
   git clone https://github.com/sebastianvasquezechavarria1234/netser.git
   ```
2. **Open the project** in Visual Studio or your preferred IDE.
3. **Build the solution** to restore dependencies.
4. **Run the application** (usually by pressing `F5` or `Ctrl+F5` in Visual Studio).
